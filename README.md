# Pencil2Diamond

**Pencil2Diamond**는 연필에서 흑연을 얻고, 이를 가공해 다이아몬드를 만드는 Unity 기반 2D 성장형 미니게임 프로젝트입니다.

현재는 튜토리얼 기반 MVP를 구현 중이며, 시작 화면, 튜토리얼 대화, 연필 깎기, 흑연 추출, 프레스 진입 흐름까지 구현되어 있습니다.
향후 다이아몬드 생성 결과, 재화 정산, 업그레이드 시스템을 연결하여 1분 단위의 반복 성장 루프를 완성하는 것을 목표로 합니다.

## 2. 목표 게임 루프

Pencil2Diamond의 최종 목표 루프는 다음과 같습니다.

```text
연필 선택
→ 연필 깎기
→ 흑연 획득
→ 프레스 가공
→ 다이아몬드 생성
→ 골드 정산
→ 업그레이드
→ 반복
```

플레이어는 연필을 깎아 흑연을 얻고, 흑연을 프레스 기계로 가공하여 다이아몬드를 생성합니다.
생성된 다이아몬드는 재화로 전환되며, 플레이어는 획득한 골드로 장비와 효율을 업그레이드합니다.

현재는 전체 루프 중 **연필 깎기 → 흑연 추출 → 프레스 진입** 흐름을 중심으로 MVP를 구현하고 있습니다.

## 4. 개발 예정 기능

앞으로 개발할 주요 기능은 다음과 같습니다.

### 4.1 프레스 결과 흐름

* 프레스 버튼 입력 처리
* 목표 온도와 현재 온도 비교
* 성공/실패 결과 판정
* 결과에 따른 다음 대화 또는 결과 화면 연결

### 4.2 다이아몬드 생성 결과

* 흑연 가공 결과 데이터 추가
* 성공 시 다이아몬드 획득 처리
* 실패 시 보상 감소 또는 재도전 처리
* 결과 UI 표시

### 4.3 재화 및 보상 시스템

* 다이아몬드 판매 또는 정산 처리
* 골드 획득 처리
* 보상 결과 화면 구현
* 플레이 기록 표시

### 4.4 업그레이드 시스템

* 채굴량 증가
* 가공 효율 증가
* 성공 확률 또는 보상 증가
* 반복 플레이 성장 구조 구현

### 4.5 저장/불러오기

* 튜토리얼 완료 여부 저장
* 골드 및 업그레이드 상태 저장
* 게임 재실행 시 진행 상태 복원

### 4.6 Android 빌드

* Android 해상도 대응
* 터치 입력 검증
* 빌드 오류 수정
* 실제 기기 실행 테스트

## 5. 씬 구조 설계

현재 프로젝트는 `MainScene` 단일 씬을 중심으로 튜토리얼 기반 MVP를 구현하고 있습니다.
향후에는 역할을 명확히 나누기 위해 `MainScene`, `GameScene`, `ResultScene` 구조로 분리할 계획입니다.

아래 구조는 현재 구현 상태와 향후 확장 방향을 함께 정리한 씬 구조 설계안입니다.

<!-- 씬 구조 이미지를 추가할 경우 아래 주석을 해제하고 이미지 경로를 맞춰 사용합니다. -->

<!-- ![Pencil2Diamond 씬 구조 설계안](Docs/scene-structure.png) -->

### 5.1 현재 구현 기준

```text
MainScene
├─ Systems
│  ├─ TalkManager
│  ├─ PencilManager
│  ├─ GameManager / GameMode
│  └─ EventSystem
├─ Cameras
│  ├─ Main Camera
│  └─ Global Light 2D
└─ UI
   ├─ StartPanel
   │  └─ BtnStart
   ├─ DialogPanel
   │  ├─ BtnNextDialog
   │  ├─ TxtScript
   │  └─ ImgPlayer
   ├─ MainCanvas
   ├─ InworkCanvas
   │  ├─ PanelSharpeningPencil
   │  ├─ PanelExtractGraphite
   │  └─ PanelPressing
   └─ PopupCanvas
```

### 5.2 향후 목표 씬 구조

```text
MainScene
→ GameScene
→ ResultScene
→ GameScene 또는 MainScene
```

| 씬           | 역할                         |
| ----------- | -------------------------- |
| MainScene   | 시작 화면, 튜토리얼 진입, 초기 메뉴      |
| GameScene   | 핵심 플레이 루프 진행               |
| ResultScene | 결과 정산, 보상 표시, 재도전 또는 메인 이동 |

> 현재는 단일 씬 구조이며, 위 3개 씬 구조는 향후 확장 설계안입니다.

## 6. 주요 시스템 구조

### 6.1 TalkManager

튜토리얼 대화 데이터를 관리하고, 대화 진행 흐름을 제어합니다.

주요 역할:

* TSV 대화 데이터 로드
* 현재 대화 인덱스 관리
* 다음 대화 출력
* 특정 대화 이후 미니게임 흐름 연결

### 6.2 PencilManager

연필 관련 데이터를 관리하고, 튜토리얼에서 사용하는 연필 작업 흐름을 담당합니다.

주요 역할:

* 연필 데이터 관리
* 연필 선택 또는 시작 처리
* 연필 깎기 단계 연결
* 작업 완료 이벤트 처리

### 6.3 PressMachine

프레스 기계의 온도 조절과 판정 로직을 담당합니다.

주요 역할:

* 현재 온도 관리
* 목표 온도 비교
* 성공 여부 판단 함수 제공
* 향후 프레스 결과 처리와 연결 예정

### 6.4 UIManager

게임 내 UI 패널의 표시와 전환을 관리하는 역할을 담당할 예정입니다.

주요 역할:

* 시작 패널 표시
* 대화 패널 표시
* 작업 패널 전환
* 결과 패널 또는 팝업 표시

## 12. 현재 상태 요약

현재 프로젝트는 튜토리얼 기반 MVP 단계입니다.

구현된 핵심 흐름:
```text
시작 화면
→ 튜토리얼 대화
→ 연필 깎기
→ 흑연 추출
→ 프레스 진입
```

앞으로 완성할 핵심 흐름:
```text
프레스 결과 판정
→ 다이아몬드 생성
→ 골드 정산
→ 업그레이드
→ 반복 플레이 루프
```
최종 목표는 짧은 시간 안에 반복 가능한 1분 성장 루프를 구현하고, 이를 Unity 클라이언트 신입 포트폴리오로 제시할 수 있는 수준까지 완성하는 것입니다.
